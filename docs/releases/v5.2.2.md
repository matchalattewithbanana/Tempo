# Tempo 5.2.2 — Expressive UI, Settings restoration and navigation improvements

**Channel:** Stable · **Android:** 8.0+ · **Package:** `me.avinas.tempo` · **Version code:** 4825 · **Source:** 32 feature and fix commits since `v5.1.70` before release metadata

This release packages the current Tempo `main` branch and companion browser extensions. It focuses on navigation stability, previously hidden settings and further Material 3 Expressive UI polish inspired by the **new Kotlin/Compose Orion Store**, not Orion Legacy.

## Changes

### Settings and navigation
- Introduced the optional **Expressive Dock** alongside the attached bar and floating dock. Selection shape/color, labels and large-font accessibility were improved.
- Added a quick top-level fade-through while preserving directional detail transitions.
- Restored individual Settings search results and direct navigation to relevant categories.
- Restored Manage Permissions, Last Player Signal, Data & Diagnostics, and Version entries.
- **Spotify Device Broadcasts** is available whether or not Spotify Web API login is connected; Spotify API history verification remains account-dependent.
- Replaced fragile numeric Settings search offsets with typed group targets and shared list keys, including the optional Analytics group.

### Personalization and listening experience
- Made Appearance Studio's accordion controls and unsaved-changes actions animate coherently.
- Added tactile response to metric tiles and Settings destinations, respecting reduced-motion preference.
- Reworked Spotlight story entry with theme-aware Material color roles, native controls, clear locked/loading states and readable contrast.
- Added selected-source feedback and artwork-visible badges to the album-art picker.
- Updated Song Details edit actions, artist/album touch targets and audio-preview presentation. The preview position indicator follows the supplied fraction directly rather than lagging behind it.

### Backups and responsive layout
- Local backup actions adapt to compact phones and large text sizes; export remains the primary action.
- Google Drive panels, backup tips, and action surfaces use semantic Material containers.
- Drive refresh controls have larger touch targets.

### Developer quality and compatibility
- Included focused unit and Android instrumentation regression tests for Settings search, navigation, accessibility, Spotlight and responsive backup actions.
- Added a strict UI maintainability audit and kept the identified larger architectural refactors separate from the release.

## Release validation and known limits

The **stable release GitHub Actions workflow must pass** version and signing checks, Android unit tests, lint, APK compilation, API 35 emulator instrumentation, browser typechecking, both browser builds and smoke checks, and SHA-256 verification **before publication**. This release was explicitly requested despite incomplete prior local/device validation; do not interpret source checks as proof of an Android build or physical-device performance.

Remaining follow-up: hands-on testing of all navigation styles, Light/Dark/OLED/custom themes, large accessibility text, background listening and vendor-specific battery policies. No listening-data schema or signing-identity migration is intended in this change set.

## Upgrade notes

Back up or export your Tempo data before upgrading. Install over your existing Tempo app only if the Android package/signing certificate matches. Do not uninstall to work around a signing mismatch until your listening history is safely backed up.
