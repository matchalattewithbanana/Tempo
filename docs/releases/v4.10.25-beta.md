# Tempo 4.10.25 Beta — Material 3 Expressive preview

**Channel:** Beta / prerelease · **Published:** 21 November 2026 · **Source commit:** [`fbdfd57`](https://github.com/matchalattewithbanana/Tempo/commit/fbdfd5769f8bf26c1720c49fafb956a5399a0f4f) · **Status:** Published and validated.

Tempo 4.10.25 Beta is the first coordinated public-test candidate for the **116 source commits** after stable `v4.9.9`, including the Material 3 Expressive design system, a substantial personalization pass, and current import, backup and performance work. **It is not the final implementation of the [remaining Expressive roadmap](../MATERIAL3_EXPRESSIVE_ROADMAP.md).**

## What's included in this candidate

- **Material 3 Expressive:** theme/motion integration, responsive navigation, floating dock option, expressive selection controls, app bars, Settings bento layout, typography, shapes, redesigned loading/empty states and detail artwork surfaces.
- **Appearance Studio:** palette presets and multi-seed color preview, saved looks, optional ambient/tilt/list effects with reduced-motion and power/thermal/low-RAM gates, and a launcher icon picker with new badge artwork.
- **Statistics and listening UI:** period/unit customization, artwork-rich insights, improved Profile, History, Spotlight and 3×3 album poster/share flows.
- **History imports and backups:** Spotify/Apple/Last.fm and other existing supported sources; overlap/duplicate controls, Google Drive/restore flows and UI updates from the current branch.
- **Browser companion:** coordinated Chromium and Firefox builds using the same numeric release series as Android.

These features are included in the verified Android and browser packages attached to the published prerelease. Automated validation passed; advanced effects remain **off by default**.

## Version provenance

- **Previous stable:** `v4.9.9` (Android versionCode `4820`).
- **Source commits after that tag, before preparation:** `116`.
- **Bounded rollover policy:** previous patch `9` + `116` commits = raw patch `125`, carried as `4.9.125 → 4.10.25` (patch cap 100; minor cap 10 inclusive).
- **Android:** `versionName=4.10.25-beta`, `versionCode=4821`, package `me.avinas.tempo`, Android 8.0+.
- **Browser:** numeric manifest `4.10.25.0` plus display `4.10.25-beta`, package/lock `4.10.25-beta` (npm SemVer). The internal `.0` is only for browser update ordering; it is **not** a numbered beta. Both browser ZIPs use `4.10.25-beta` in their filenames.
- **Signing:** existing fork beta signing certificate is required; never substitute a random CI runner key for a published update.

## Validation and known beta limitations

[GitHub Actions run #44825331651](https://github.com/matchalattewithbanana/Tempo/actions/runs/44825331651) **passed** Android unit tests (1,083), Android lint, instrumentation tests (63), APK/signature/version checks, browser typecheck/build/smoke tests, and downloaded archive SHA-256 verification. The prerelease points to the verified source commit and contains all four expected assets. A targeted lint baseline tracks 60 pre-existing Compose locale findings for follow-up in [issue #92](https://github.com/matchalattewithbanana/Tempo/issues/92); strict lint checking remains enabled for new errors.

Real-device listening, Android widgets, Sign In/Drive setup, launcher icon cache updates, animated/tilt effects, battery and thermal behavior, Light/Dark/OLED contrast, and large-font accessibility still require explicit physical-device testing. Please report device model, Android version, affected page, reproduction steps and screenshots (without account secrets).
