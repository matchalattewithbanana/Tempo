# Releases

The authoritative repository release catalog is maintained in [Release catalog](README.md).

Use the catalog to distinguish **published binaries** from newer source changes on `main`. Version tags identify the source used for a specific APK/browser bundle; documentation and issue fixes can be newer than the latest published artifact.

Before reinstalling or changing signing identity, export and verify a backup. GitHub APKs are separate from upstream Google Play distribution and may require their own provider/OAuth configuration.
