# Tempo 4.9.9

Tempo 4.9.9 brings Apple Music history import, more customizable listening stats,
and expanded sharing. It is the first coordinated GitHub release of the Android
app and the Chromium and Firefox companions.

## What's new

- Import Apple Music Play Activity CSV or an Apple privacy-export ZIP.
- Choose your Stats ranking defaults, minutes, hours, or days, and the metric in the summary.
- Build and share a 3×3 album poster by hand or from the current Stats period.
- Share albums, profiles, completed challenges, and recent listening history as cards. Save cards as PNGs or share text where available.
- Customize the Profile layout and use refreshed Android widgets that open Stats for the matching period.
- Reduce redundant Stats and artwork work. Match overlapping imports by timing and source, and avoid assigning guessed watch time to timestamp-only YouTube entries.

## Downloads

- **Android** — `Tempo-4.9.9.apk`, Android 8.0+, package `me.avinas.tempo`, version code 4820. This debug-variant APK uses the established fork signing key. Export a backup before upgrading and install over the current app only if the signing certificate matches.
- **Chromium** — Extract `Tempo-Stats-Chromium-4.9.9.zip` and load it as an unpacked extension.
- **Firefox 140+** — Extract `Tempo-Stats-Firefox-4.9.9.zip` and load its manifest as a temporary add-on. The unsigned GitHub package is removed when Firefox restarts.

Use the SHA-256 entries in `SHA256SUMS.txt` to check all three files.
The release workflow gates publication on Android unit tests, lint, emulator
tests, extension builds and smoke tests, and signing and package verification.
Physical-device playback, widget behavior, accessibility, and battery performance
require separate verification.
