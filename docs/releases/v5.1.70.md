# Tempo 5.1.70 — Navigation Hotfix

**Channel:** Stable · **Android:** 8.0+ · **Package:** `me.avinas.tempo` · **Version code:** 4824

A focused hotfix for broken **Floating Dock** and **Short Bar** navigation in Tempo 5.1.69.

## Fixed
- Replaced the inadvertently restored `ShortNavigationBar`/`ShortNavigationBarItem` implementation with the stable Material `NavigationBar`/`NavigationBarItem` three-destination component.
- Restored reliable Home, Stats, and History navigation slots, persistent labels, selected indicators, and theme-aware foreground/background roles.
- Fixed navigation-system inset handling: the attached bottom bar occupies its proper system-inset area, while Floating Dock stays lifted clear of the system navigation region.
- Preserved distinct attached-bar and floating-dock shapes, sizing, and surfaces without duplicating navigation behavior.

## Scope
No listening history, import, tracking, or database schema changes. Android package ID and established debug signing identity remain unchanged. The browser companion ships alongside Android with synchronized version numbers; its tracking logic is unchanged.
