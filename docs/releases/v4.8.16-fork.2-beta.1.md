# Tempo 4.8.16-fork.2-beta.1 — Appearance Studio beta

**17 November 2026 · Android 8.0+ · prerelease APK**

## What is new

- Six appearance looks: Abyss, Obsidian Gold, Aurora, Glacier, Ember and Solstice, plus OLED black.
- Opt-in experimental Light and Follow System modes using semantic Material3 color palettes. Abyss Dark remains the default.
- Heading styles, bold text, comfortable/compact card density, corner shapes, Solid/Satin surfaces, wallpaper accents (Android 12+), artwork accents and adaptive reduced effects.
- Custom Home section order and visibility, Stats opening filters, and an optional compact, cover-art-enabled playback strip that does not duplicate Home's live card.
- Up to twelve saved looks with appearance-only JSON import/export. Tracking history and account credentials are not included.
- Palette and contrast improvements across primary UI, imports, backups, dialogs, menus and shared components.

## Testing

This prerelease is published only if the beta workflow succeeds at **unit tests, lint, APK assembly and Android emulator tests**. A SHA-256 checksum is attached. Automated tests are not a substitute for visual and real-world playback testing on a physical device.

## Installation

**Back up listening history before replacing the app.** This APK is **debug signed**, not a Google Play production release. Unless its signer matches your existing installation, Android will block an in-place update. Export data before uninstalling. A persistent debug signing key may or may not be configured for this repository.

Package ID: `me.avinas.tempo`. Version code: `4817`. Not rebranded yet.

## Beta limitations

- Light and System modes remain **experimental**; some artwork, overlays and special-purpose visualizations may need contrast work. Switch to Dark or OLED if a screen is hard to read.
- Spotify history availability, background capture, and exact listening-time accounting still depend on player and Android behavior; test with real playback before relying on statistics.
- Google sign-in/Google Drive backup requires the app's correct OAuth configuration and signing SHA-1, which is not assured in fork APKs.
- Compact Now Playing is a visual status strip, not a playback controller.
- Experimental heavy blur/refraction is deferred until physical-device performance measurements.

Please report regressions at [GitHub issues](https://github.com/matchalattewithbanana/Tempo/issues), including device, Android version, preset/tone and relevant playback app.
